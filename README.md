# Sistem de Rezervări pentru un Cinema

Acest proiect reprezintă o aplicație C++ orientată pe obiecte (OOP) pentru gestionarea rezervărilor într-un cinematograf. 
Proiect realizat de Mandrescu Matei sgr. 3121b.

## Obiectivele Proiectului
- Gestionarea entităților principale: `Film`, `Sala`, `Rezervare`.
- Implementarea conceptelor OOP: Încapsulare, Moștenire, Polimorfism.
- Tratarea excepțiilor pentru validări (ex: loc ocupat, index invalid).

## Tehnologii Utilizate
- **Limbaj:** C++ (Standard C++17)
- **Sistem de Build:** CMake
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
